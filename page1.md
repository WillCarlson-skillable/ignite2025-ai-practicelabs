## Introduction

This AI Practice Lab is designed to help you reinforce and expand the skills you gained in the related learning lab with the same title. This lab uses the same technical setup and resources, but gives you the freedom to Learn, Practice, or Challenge yourself using an LLM-powered assistant. You can prompt the assistant to generate exercises, offer support, or simulate real-world scenarios-limited to topics relevant to this lab's environment to deepen your mastery and confidence.

<br>
## The Environment

This environment contains all the same resources and capabilities as the learning lab with the same title. Unlike that environment, this one can be used countless times with endless variation, allowing you to continue to grow your skills and confidence.

## The AI Practice Generator

On the next page you will see the AI Practice Generator. It is made up of four key parts:
| Control | Description | Image |
| ------- | ----------- | :-----: |
| Style selector | Used to select the style your response will be provided in. | !IMAGE[AI_Practice_Lab_Style_Selector.png](/images/AI_Practice_Lab_Style_Selector.png) |

| | |

<br>
The AI Practice Generator remembers everything you've asked it in the lab. Feel free to continue refining and prompting your way to mastery of the topic. You can also ask the same question multiple times, taking advantage of the different response styles if you're ever stuck.
